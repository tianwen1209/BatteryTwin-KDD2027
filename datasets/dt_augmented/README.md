# DT-Augmented Examples

This directory contains two compact examples generated by the BatteryTwin digital twin. They are provided to document the public data format without including raw experimental measurements.

| File | Operating condition | Arrays |
| --- | --- | --- |
| `virtual_cell_25c_example.npz` | Virtual cell at 298.15 K | `voltages` with shape `(861, 128)` and `soh` with shape `(861,)`. |
| `temperature_shift_10c_example.npz` | Virtual cell at 283.15 K | `voltages` and `temperatures` with shape `(861, 128)`, plus `soh` with shape `(861,)`. |

The first dimension indexes aging cycles. Each row is a uniformly sampled discharge curve with 128 points. Voltage is in V, temperature is in K, and SOH is normalized to the first simulated cycle.

```python
import numpy as np

example = np.load("virtual_cell_25c_example.npz", allow_pickle=False)
voltages = example["voltages"]
soh = example["soh"]
```
