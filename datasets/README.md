# BatteryTwin Datasets

BatteryTwin data assets are organized by provenance.

| Directory | Description |
| --- | --- |
| [`experimental/`](experimental/) | Release notice for real experimental data and benchmark records. |
| [`dt_augmented/`](dt_augmented/) | Public examples generated by the calibrated digital twin. |

The real dataset and the complete benchmark package will be released after acceptance. The DT-augmented examples are provided now to document the output format used by the simulation and curation workflow.
