# BatteryTwin Datasets

BatteryTwin data assets are organized by provenance.

| Directory | Description |
| --- | --- |
| [`experimental/`](experimental/) | Download instructions for the real experimental battery dataset. |
| [`dt_augmented/`](dt_augmented/) | Public examples generated by the calibrated digital twin. |

The real experimental battery dataset, containing battery cycling results measured at 2C and 3C C-rates and at 25 °C and 40 °C ambient temperatures, is available on OneDrive:

**[Download the BatteryTwin dataset (OneDrive)](https://entuedu-my.sharepoint.com/:f:/g/personal/tianwen001_e_ntu_edu_sg/IgBUuRkdcQGoT62Vo3JPqvCJAerBQn7HmSPfo838sJILnH8?e=gm1uAy)**

The DT-augmented examples in this repository document the output format used by the simulation and curation workflow.
